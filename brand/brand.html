From setup to a usable file

A retrieval flow
an agent can finish.

Start with provider discovery. Search or select one item, inspect a bounded preview, then export into a new private folder. Every step returns structured data and a useful failure.

01 / DIAGNOSE

Check the host.

stillport doctor reports local prerequisites without opening Photos or contacting Google.

02 / DISCOVER

Choose honestly.

stillport capabilities names each provider’s search engine, permission, and limits.

03 / INSPECT

Preview one item.

Apple, Google, and macOS Takeout create a still no larger than 1600 pixels. Other Takeout hosts copy compatible stills unchanged.

04 / EXPORT

Copy without overwrite.

Each export gets a new private directory. Stillport returns the exact paths and never edits the library.

Privacy is part of the interface

A port, not a new photo service.

No hosted intermediaryCommands run on your machine. Stillport has no telemetry or AI API key.
Read-only provider scopeNo delete, edit, or library mutation commands are exposed.
Selected Google accessA person chooses items in Google Photos Picker. There is no unattended library search.
Local Takeout indexMetadata stays under your Stillport data directory. Archive media is not copied during import.

Type with a human side.

Within reach.

Georgia for the invitation. System sans for explanation. Monospace for exact commands. The lowercase wordmark stays simple.

Say what it does.

Use concrete verbs: search, choose, preview, export. Name limitations where they affect a decision. Avoid claims of unrestricted Google access, guaranteed AI search, or a shared verified OAuth app.

The mark is original vector artwork. The harbor photograph is a synthetic public fixture used to prove the retrieval path. No private photographs appear in the brand assets.
